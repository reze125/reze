# Content Repurposing

## Transformation Matrix
| Source | Target |
|--------|--------|

| Blog post | Video script |

## Twitter Thread Format
```
1/7 [Hook - 흥미로운 질문]

2/7 [문제 제기]

3/7 [해결책 1]

4/7 [해결책 2]

5/7 [해결책 3]

6/7 [결론]

7/7 [CTA + 블로그 링크]
```

## Best Practices
1. 각 플랫폼 특성에 맞게 조정
2. 핵심 메시지 유지
3. 각 플랫폼용 CTA
4. 원본 링크 포함
