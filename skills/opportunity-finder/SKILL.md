# Opportunity Finder

## Opportunity Sources
1. **Keyword Gaps**: 검색량 높고 경쟁 낮은 키워드
2. **Feature Gaps**: 경쟁사에 없는 기능
3. **Price Gaps**: 가격 공백대
4. **New Tech**: 신기술 활용 가능성

## Evaluation Criteria
- Market Size (TAM)
- Competition Level
- Implementation Difficulty
- Revenue Potential

## Output Format
```
## Opportunity: [이름]
### Source
[어디서 발견했는지]

### Analysis
- Market: [크기/성장]
- Competition: [경쟁 수준]
- Fit: [우리 역량과 맞는지]

### Action
- [ ] 블로그 작성
- [ ] 제품 기능 추가
- [ ] 새 제품 기획
```
