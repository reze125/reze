# Growth-Intel Meta-Skill

성장을 위한 데이터 인텔리전스. 경쟁사 동향, 콘텐츠 기회, 키워드 분석.

## 핵심 워크플로우

### 경쟁사 모니터링
1. Tavily로 경쟁사 최신 콘텐츠 검색
2. 새 기능/가격 변경 감지
3. 우리와의 차이점 분석
4. 대응 전략 제안

### 콘텐츠 갭 분석
1. 경쟁사가 다루는데 우리가 안 다루는 주제 발굴
2. 검색량 + 경쟁도 분석
3. 우선순위 제안

### 키워드 기회
1. 트렌드 상승 키워드 발굴
2. 롱테일 키워드 분석
3. 블로그 글감 제안

### 트래픽 분석
1. Plausible/GA 데이터 수집
2. 인기 콘텐츠 파악
3. 이탈 페이지 분석
4. 개선 제안

## 출력 형식
모든 분석은 action_items (실행 가능한 다음 행동) 포함 필수.
